# Checklist

- [ ] 默认关闭：全新安装或旧 `assets.json` 升级后，保护口令为关闭，程序行为与之前一致
- [ ] 设置页存在「保护口令」区块，含启用开关、口令、确认口令、空闲时长档位（1/5/10/15/30/60，默认 10 分钟）
- [ ] 设置页风险提示文案包含数据文件路径 `%LocalAppData%\FastRdp\RemoteOps\assets.json` 与「请提前备份」说明
- [ ] 保存校验：启用时口令为空 / 少于 4 位 / 两次不一致，均被拒绝并有明确提示，设置不落盘
- [ ] 已存在口令时，口令框留空保存视为「不修改口令」而非清空
- [ ] 口令以 PBKDF2-SHA256 + 随机盐哈希存储，`assets.json` 中无明文口令
- [ ] 关闭保护口令后 Salt/Hash 被清空，锁定行为立即停止
- [ ] 空闲达到设定时长后主窗口自动锁定；有持续键鼠输入时不锁定
- [ ] 空闲检测使用系统级 `GetLastInputInfo`，窗口隐藏/后台时同样生效
- [ ] 存在可见模态子窗口时跳过本次自动锁定
- [ ] 锁定覆盖层遮挡整个主窗口，锁定期间无法操作资产列表与工具栏
- [ ] 设置页提供「立即锁定」按钮，保护口令启用时可用、关闭时禁用
- [ ] 手动「立即锁定」可随时进入锁定态，输入正确口令后恢复
- [ ] 自动锁定与手动锁定都会关闭主窗口的所有已打开子窗口（独立 SSH 窗口、对话框），锁定后无窗口可绕过
- [ ] 输入正确口令后解锁，覆盖层关闭、错误计数清零、空闲计时重新开始
- [ ] 输入错误口令显示剩余尝试次数并清空输入框
- [ ] 回车键可提交解锁
- [ ] 已启用保护口令时，程序启动后主窗口立即处于锁定态
- [ ] 连续第 5 次错误后，口令输入与解锁按钮被禁用，只提供「清空数据并进入」
- [ ] 清空数据前有二次确认，确认后删除 `assets.json`，程序以空数据且保护口令关闭状态进入
- [ ] 取消清空时保持锁定，且不再接受口令输入
- [ ] 中英文文案成对存在，无缺失键、无硬编码中文
- [ ] `ProtectionIdleMinutes` 非法值（不在档位内）回落为 10
- [ ] `ProtectionEnabled=true` 但 Salt/Hash 为空时回落为关闭，避免不可解锁的死锁
- [ ] 单元测试覆盖：哈希生成/校验、存储向前兼容与非法值回落
- [ ] `dotnet build OpenNodeDesk.sln -c Debug --nologo -v q` 0 警告 0 错误
- [ ] `dotnet test tests\OpenNodeDesk.Tests\OpenNodeDesk.Tests.csproj -c Release --nologo` 全部通过
- [ ] 未引入对本功能之外行为的改动（不改动 `AssetListFontSize` 等无关逻辑）
