# OpenNodeDesk для macOS

**Локальный в первую очередь хаб удалённых подключений для macOS.** Держите все серверы, учётные
записи и параметры подключений в одном списке — с поиском, повторным использованием и переносимостью —
и переходите от «мне нужна эта машина» к живому сеансу за три шага.

## Что это

OpenNodeDesk — это не очередной клиент удалённого рабочего стола. Отрисовка удалённого экрана,
перенаправление периферии и аудио/видео обеспечиваются самыми зрелыми клиентами платформы —
Microsoft Windows App для RDP, встроенным Screen Sharing для VNC и встроенным терминалом для SSH.
OpenNodeDesk отвечает за **остальные 90%**: реестр ресурсов, параметры, учётные данные, напоминания
об истечении срока действия и историю подключений.

Принципы дизайна:

- **Подключение за три секунды** — поиск, нажатие Return, сеанс открыт.
- **Локальный в первую очередь, работает офлайн, без учётной записи** — открывайте, ищите,
  редактируйте и подключайтесь без сети.
- **Не изобретаем велосипед** — отрисовка удалённого экрана отдаётся лучшему клиенту платформы.
- **Объяснимые параметры** — у каждого действующего значения указан источник: *пользовательский /
  шаблон / по умолчанию*.
- **Объяснимые ошибки** — ошибки сопровождаются причиной и практическими рекомендациями, а не «сырым»
  кодом.
- **Переносимые данные** — экспорт и импорт в один клик; перенос на другую машину одним файлом.
- **Клавиатура в первую очередь** — у каждого ключевого действия есть сочетание клавиш.

## Возможности

### Центр ресурсов
- Табличная и сеточная раскладки; поиск по имени, хосту, группе, ответственному и заметкам.
- Избранное, недавние подключения и сворачиваемые группы на боковой панели.
- Показ/скрытие и перестановка отдельных столбцов, а также глобальный размер шрифта списка.
- Напоминания об истечении: ресурсы, у которых срок истекает в течение 30 дней (или уже истёк),
  помечаются прямо в списке.
- Обнаружение дубликатов по **хосту + порту** при импорте.

### RDP / SSH / VNC
- Порты по умолчанию для каждого протокола (3389 / 22 / 5900) со свободным переопределением.
- **RDP** — создаёт временный файл `.rdp` для Microsoft Windows App; оконный режим, глубина цвета,
  перенаправление диска/звука/буфера обмена и разрешение настраиваются. Исполняемые файлы FreeRDP
  обнаруживаются и запускаются сразу с сохранённым паролем, минуя запрос учётных данных. Автозаполнение
  пароля в диалоге учётных данных Windows App использует API Accessibility macOS.
- **VNC** — по умолчанию использует встроенный Screen Sharing; для внешних клиентов (RealVNC,
  TigerVNC…) можно настроить шаблон аргументов запуска с поддержкой
  `{host} {port} {display} {user} {password}`.
- **SSH** — настоящий терминал, встроенный в приложение (SwiftTerm), с jump-хостом (`-J`),
  аутентификацией по приватному ключу, поддержкой парольной фразы ключа и настраиваемыми
  дополнительными аргументами `ssh`.

### Шаблоны подключений
Многоразовые наборы параметров (протокол, порт, имя пользователя, перенаправления, оконный режим,
глубина цвета, размер окна SSH). У каждого вычисленного параметра отображается его текущее значение
**и источник, из которого оно получено**.

### Рабочее пространство сеансов
- Несколько сеансов рядом с переключаемыми схемами разбиения и разворотом отдельного сеанса на весь
  экран.
- Поле «открыть ресурс» на панели инструментов: введите имя или хост и нажмите Return либо выберите
  из списка.
- Поддерживаются отдельные окна SSH, если вы предпочитаете держать их вне рабочего пространства.

### Передача файлов по SFTP
- Полноценный обозреватель удалённых файлов для каждого ресурса: каталоги, размеры, права доступа,
  время изменения.
- Загрузка и скачивание файлов или целых каталогов с докачкой (`reput` / `reget`).
- Создание каталогов, удаление файлов или пустых каталогов, перетаскивание файлов в текущий каталог.
- Доступно с панели инструментов сеанса и из контекстного меню терминала SSH.

### Контекстное меню терминала SSH
Копирование, вставка, выделение всего и «передача файлов» прямо в месте ввода. Когда удалённая
программа захватывает мышь (vim, tmux), правый клик, как и ожидается, передаётся удалённой программе.

### Учётные данные
- Пароли и парольные фразы ключей хранятся **только** в Keychain macOS и никогда — в файлах данных.
- Удаление ресурса или снятие флажка «запомнить пароль» удаляет запись из Keychain.

### Импорт, экспорт и синхронизация
- Импорт из CSV или Excel (`.xlsx`) с автоматическим сопоставлением столбцов и предпросмотром
  проверки.
- Экспорт в CSV или JSON с выбором отдельных полей; конфиденциальные поля по умолчанию не отмечены.
- Облачная синхронизация сначала загружает предпросмотр и объединяет только выбранное — только
  ресурсы и шаблоны, но никогда пароли.

### Проверка доступности
TCP-проверка отдельных ресурсов, выделенных или всего реестра — по запросу или по таймеру.

### Блокировка приложения (защитная парольная фраза)
- Необязательная блокировка парольной фразой с авто-блокировкой при простое (1–60 минут).
- Хеширование парольной фразы с помощью **PBKDF2-SHA256**, 100 000 итераций и случайной 128-битной
  соли.
- Код восстановления выдаётся один раз при настройке (Crockford Base32, устойчив к путанице
  `O/0`, `I/L/1`).
- Настраивается: после 5 неудачных попыток подряд автоматически стереть локальные данные либо
  остаться заблокированным и требовать ручного стирания.

### Внешний вид и справка
- Тема «Как в системе» / светлая / тёмная; интерфейс на упрощённом китайском и английском языках.
- Встроенное руководство пользователя, охватывающее использование VNC, диагностику по каждому
  протоколу, места хранения данных и конфиденциальность учётных данных.

## Системные требования

| Пункт | Требование |
| --- | --- |
| macOS | 14.0 (Sonoma) или новее |
| Клиент для RDP | Microsoft Windows App (из App Store) |
| Клиент для VNC | Встроенный Screen Sharing либо RealVNC / TigerVNC и подобные |
| Автозаполнение пароля RDP | Разрешение Accessibility для OpenNodeDesk |
| Сборка из исходного кода | Xcode 16 или новее (тулчейн Swift 6) |

## Установка

1. Скачайте `OpenNodeDesk-<version>-macos.zip` со страницы
   [Releases](https://github.com/OpenNodeSaas/OpenNodeDesk-macos/releases).
2. Распакуйте и перетащите `OpenNodeDesk.app` в `/Applications`.
3. Сборка не нотаризована Apple, поэтому при первом запуске Gatekeeper может выдать предупреждение —
   щёлкните приложение правой кнопкой и выберите **Открыть** либо разрешите его в разделе
   *Системные настройки → Конфиденциальность и безопасность*.

## Сборка из исходного кода

```bash
git clone https://github.com/OpenNodeSaas/OpenNodeDesk-macos.git
cd OpenNodeDesk-macos
make bundle   # release build + dist/OpenNodeDesk.app
make run      # build, bundle and launch
```

Полезные цели: `make check` (компиляция и вывод диагностики), `make clean` (удаление `.build` и
`dist`), `make reset` (удаление локальных данных из `~/Library/Application Support/RemotePilot`).

## Данные и конфиденциальность

- Ресурсы, шаблоны и настройки хранятся в `~/Library/Application Support/RemotePilot`
  (`assets.json`, `settings.json`).
- Пароли и парольные фразы ключей записываются только в Keychain macOS; они никогда не попадают в
  экспорт или в данные синхронизации. Поэтому при переходе на другую машину их нужно вводить заново.
- Приложение полностью работает офлайн; адрес облачной синхронизации необязателен и задаётся
  пользователем.

## Замечания и ограничения

- Windows App в macOS не может размещать несколько сеансов в виде вкладок в одном окне; при выборе
  вкладочного режима окно открывается как обычное. Для нескольких сеансов используйте рабочее
  пространство сеансов.
- Если клиент для RDP не установлен, при попытке подключения объясняется, что и откуда нужно
  установить.
- Внутренний идентификатор пакета `com.remotepilot.macos` и каталог данных
  `RemotePilot` намеренно оставлены без изменений после переименования, чтобы существующие ресурсы,
  настройки и записи Keychain продолжали работать после обновления.
