# macOS용 OpenNodeDesk

**macOS를 위한 로컬 우선(local-first) 원격 연결 허브.** 모든 서버, 계정, 연결 파라미터를 검색
가능하고 재사용 가능한 하나의 휴대용 목록에 담아 두고, "저 머신이 필요해"에서 실제 세션까지 세
단계로 도달하세요.

## 무엇인가

OpenNodeDesk은 또 하나의 원격 데스크톱 클라이언트가 아닙니다. 원격 화면 렌더링, 주변기기
리디렉션, 오디오/비디오는 플랫폼에서 가장 성숙한 클라이언트를 따릅니다 — RDP에는 Microsoft Windows
App, VNC에는 내장 화면 공유, SSH에는 내장 터미널을 사용합니다. OpenNodeDesk은 **나머지 90%**를
담당합니다: 인벤토리, 파라미터, 자격 증명, 만료 알림, 연결 기록입니다.

설계 원칙:

- **3초 연결** — 검색하고 Return 키를 누르면 세션이 열립니다.
- **로컬 우선, 오프라인 지원, 계정 불필요** — 네트워크 없이 열고, 검색하고, 편집하고, 연결할 수 있습니다.
- **바퀴를 다시 발명하지 않기** — 원격 렌더링은 플랫폼 최고의 클라이언트에 맡깁니다.
- **설명 가능한 파라미터** — 모든 적용 값에는 *사용자 정의 / 템플릿 / 기본값* 표시가 붙습니다.
- **설명 가능한 실패** — 오류에는 원인과 실행 가능한 제안이 함께 제공되며, 원시 코드만 던져지지 않습니다.
- **휴대 가능한 데이터** — 클릭 한 번으로 내보내기와 가져오기; 파일 하나로 머신을 이전합니다.
- **키보드 우선** — 모든 핵심 동작에 단축키가 있습니다.

## 기능

### 자산 센터
- 테이블 및 그리드 레이아웃; 이름, 호스트, 그룹, 소유자, 메모를 대상으로 검색.
- 사이드바의 즐겨찾기, 최근 연결, 접을 수 있는 그룹.
- 열별 표시/숨기기와 순서 변경, 그리고 전체 목록 글꼴 크기.
- 만료 알림: 30일 이내에 만료되는(또는 이미 만료된) 자산은 해당 위치에 표시됩니다.
- 가져오기 시 **호스트 + 포트** 기준 중복 감지.

### RDP / SSH / VNC
- 프로토콜별 기본 포트(3389 / 22 / 5900)와 자유로운 재정의.
- **RDP** — Microsoft Windows App용 임시 `.rdp` 파일을 생성합니다; 창 모드, 색 심도,
  드라이브/오디오/클립보드 리디렉션, 해상도를 모두 설정할 수 있습니다. FreeRDP 바이너리가 감지되면
  저장된 비밀번호로 직접 실행하여 자격 증명 입력 프롬프트를 건너뜁니다.
  Windows App 자격 증명 대화상자의 비밀번호 자동 입력은 macOS Accessibility API를 사용합니다.
- **VNC** — 기본적으로 내장 화면 공유를 사용합니다; 외부 뷰어(RealVNC, TigerVNC…)는
  `{host} {port} {display} {user} {password}`를 지원하는 실행 인자 템플릿으로 설정할 수 있습니다.
- **SSH** — 앱에 내장된 실제 터미널(SwiftTerm)로, 점프 호스트(`-J`), 개인 키 인증, 키 암호 문구
  지원, 추가 `ssh` 인자 설정을 제공합니다.

### 연결 템플릿
재사용 가능한 파라미터 집합(프로토콜, 포트, 사용자 이름, 리디렉션, 창 모드, 색 심도, SSH 창
크기). 해석된 모든 파라미터는 현재 값과 **그 값이 어디에서 왔는지**를 함께 보여줍니다.

### 세션 워크스페이스
- 전환 가능한 분할 레이아웃으로 여러 세션을 나란히 표시하며, 세션별 최대화를 지원합니다.
- 툴바의 "자산 열기" 상자: 이름이나 호스트를 입력하고 Return 키를 누르거나 목록에서 선택합니다.
- 워크스페이스 밖에서 사용하고 싶을 때를 위한 별도 SSH 창을 지원합니다.

### SFTP 파일 전송
- 자산별 완전한 원격 파일 브라우저: 디렉터리, 크기, 권한, 수정 시간.
- 파일 또는 폴더 전체 업로드 및 다운로드, 이어받기 지원(`reput` / `reget`).
- 폴더 생성, 파일 또는 빈 폴더 삭제, 현재 폴더로 파일 끌어다 놓기.
- 세션 툴바와 SSH 터미널 컨텍스트 메뉴에서 사용할 수 있습니다.

### SSH 터미널 컨텍스트 메뉴
입력하는 바로 그 자리에서 복사, 붙여넣기, 모두 선택, "파일 전송"을 사용할 수 있습니다. 원격
프로그램(vim, tmux)이 마우스를 가로챌 때는 오른쪽 클릭이 예상대로 원격 프로그램으로 전달됩니다.

### 자격 증명
- 비밀번호와 키 암호 문구는 **오직** macOS Keychain에만 저장되며, 데이터 파일에는 절대 저장되지 않습니다.
- 자산을 삭제하거나 "비밀번호 기억"을 해제하면 Keychain 항목이 제거됩니다.

### 가져오기, 내보내기 및 동기화
- 자동 열 매핑과 유효성 검사 미리보기를 갖춘 CSV 또는 Excel(`.xlsx`) 가져오기.
- 필드별 선택이 가능한 CSV 또는 JSON 내보내기; 민감한 필드는 기본적으로 선택 해제됩니다.
- 클라우드 동기화는 먼저 미리보기를 가져오고 선택한 항목만 병합합니다 — 자산과 템플릿만
  해당하며 비밀번호는 절대 포함되지 않습니다.

### 도달 가능성 프로빙
단일 자산, 선택 항목 또는 전체 인벤토리에 대한 TCP 프로빙을 요청 시 또는 타이머로 수행합니다.

### 앱 잠금(보호 암호 문구)
- 유휴 시 자동 잠금(1~60분)을 지원하는 선택적 암호 문구 잠금.
- **PBKDF2-SHA256**, 100,000회 반복, 무작위 128비트 솔트로 암호 문구를 해싱합니다.
- 설정 시 복구 코드가 한 번 발급됩니다(Crockford Base32, `O/0`, `I/L/1` 허용).
- 설정 가능: 5회 연속 실패 시 로컬 데이터를 자동으로 삭제하거나, 잠금 상태를 유지하고 수동 삭제를
  요구합니다.

### 모양 및 도움말
- 시스템 설정 따르기 / 라이트 / 다크 테마; 중국어 간체 및 영어 인터페이스.
- VNC 사용법, 프로토콜별 문제 해결, 데이터 위치, 자격 증명 개인정보 보호를 다루는 앱 내 도움말
  설명서.

## 요구 사항

| 항목 | 요구 사항 |
| --- | --- |
| macOS | 14.0 (Sonoma) 이상 |
| RDP 캐리어 | Microsoft Windows App(App Store에서 제공) |
| VNC 캐리어 | 내장 화면 공유, 또는 RealVNC / TigerVNC 등 |
| RDP 비밀번호 자동 입력 | OpenNodeDesk에 대한 Accessibility 권한 |
| 소스에서 빌드 | Xcode 16 이상(Swift 6 툴체인) |

## 설치

1. [Releases](https://github.com/OpenNodeSaas/OpenNodeDesk-macos/releases) 페이지에서
   `OpenNodeDesk-<version>-macos.zip`을 다운로드합니다.
2. 압축을 풀고 `OpenNodeDesk.app`을 `/Applications`로 끌어다 놓습니다.
3. 이 빌드는 Apple의 공증(notarisation)을 받지 않았으므로 첫 실행 시 Gatekeeper가 경고할 수 있습니다 — 앱을
   오른쪽 클릭하고 **열기**를 선택하거나, *시스템 설정 → 개인정보 보호 및 보안*에서 허용하십시오.

## 소스에서 빌드

```bash
git clone https://github.com/OpenNodeSaas/OpenNodeDesk-macos.git
cd OpenNodeDesk-macos
make bundle   # release build + dist/OpenNodeDesk.app
make run      # build, bundle and launch
```

유용한 타깃: `make check`(컴파일 및 진단 표시), `make clean`(`.build`와
`dist` 삭제), `make reset`(`~/Library/Application Support/RemotePilot`의 로컬 데이터 제거).

## 프로젝트 구조

```
Sources/RemotePilot/
├── App/            앱 진입점, 전역 모델, 명령 및 메뉴
├── Core/           SSH/SFTP, Keychain, 프로빙, 가져오기/내보내기, 동기화, 캐리어 감지, RDP 자동 입력
├── Design/         디자인 토큰 및 공용 컴포넌트
├── Localization/   중국어 원본 문자열 + 영어 문자열 테이블
├── Models/         자산, 템플릿, 설정 및 런타임 모델
├── Views/          사이드바, 자산 센터, 워크스페이스, 세션, 설정, 도움말, 대화상자
└── main.swift      진입점(SSH_ASKPASS 헬퍼 역할도 겸함)
Resources/          Info.plist 및 앱 아이콘
docs/              설계 문서 및 번역된 README
```

## 데이터 및 개인정보 보호

- 자산, 템플릿, 설정은 `~/Library/Application Support/RemotePilot`
  (`assets.json`, `settings.json`)에 저장됩니다.
- 비밀번호와 키 암호 문구는 macOS Keychain에만 기록되며, 내보내기나 동기화 페이로드에 포함되지
  않습니다. 따라서 다른 머신으로 이전할 때는 다시 입력해야 합니다.
- 앱은 완전히 오프라인으로 동작합니다; 클라우드 동기화 엔드포인트는 선택 사항이며 사용자가 지정합니다.

## 참고 사항 및 제한 사항

- macOS의 Windows App은 여러 세션을 한 창의 탭으로 호스팅할 수 없습니다; 탭 창 모드를
  선택해도 일반 창이 열립니다. 여러 세션을 사용하려면 세션 워크스페이스를 사용하십시오.
- RDP 캐리어가 설치되어 있지 않으면, 연결 시도 시 무엇을 어디에서 설치해야 하는지 안내합니다.
- 내부 번들 식별자 `com.remotepilot.macos`와 데이터 디렉터리
  `RemotePilot`은 이름 변경 이후 의도적으로 그대로 유지되어, 업그레이드 후에도 기존 자산, 설정,
  Keychain 항목이 계속 작동합니다.
