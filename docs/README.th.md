# OpenNodeDesk for macOS

**ศูนย์กลางการเชื่อมต่อระยะไกลที่ทำงานภายในเครื่องเป็นหลักสำหรับ macOS** เก็บเซิร์ฟเวอร์ บัญชี และ
พารามิเตอร์การเชื่อมต่อทุกอย่างไว้ในรายการเดียวที่ค้นหาได้ ใช้ซ้ำได้ และพกพาสะดวก — แล้วไปจาก
"ฉันต้องการเครื่องนั้น" สู่เซสชันที่ใช้งานได้จริงในสามขั้นตอน

## มันคืออะไร

OpenNodeDesk ไม่ใช่โปรแกรมไคลเอนต์เดสก์ท็อประยะไกลอีกตัวหนึ่ง การแสดงผลหน้าจอระยะไกล การส่งผ่าน
อุปกรณ์ต่อพ่วง และเสียง/วิดีโอ ใช้ไคลเอนต์ที่สมบูรณ์แบบที่สุดบนแพลตฟอร์ม — Microsoft Windows App
สำหรับ RDP, Screen Sharing ที่มีมาให้สำหรับ VNC และเทอร์มินัลที่มีมาให้สำหรับ SSH ส่วน OpenNodeDesk ดูแล
**อีก 90% ที่เหลือ**: คลังทรัพย์สิน พารามิเตอร์ ข้อมูลรับรอง การแจ้งเตือนการหมดอายุ และ
ประวัติการเชื่อมต่อ

หลักการออกแบบ:

- **เชื่อมต่อในสามวินาที** — ค้นหา กด Return เซสชันก็เปิดขึ้น
- **ทำงานภายในเครื่องเป็นหลัก ใช้งานออฟไลน์ได้ ไม่ต้องมีบัญชี** — เปิด ค้นหา แก้ไข และเชื่อมต่อได้โดยไม่ต้องมีเครือข่าย
- **ไม่ต้องสร้างล้อใหม่** — การแสดงผลระยะไกลเป็นหน้าที่ของไคลเอนต์ที่ดีที่สุดบนแพลตฟอร์ม
- **พารามิเตอร์ที่อธิบายได้** — ค่าที่มีผลทุกค่าจะถูกกำกับว่า *custom / template / default*
- **ข้อผิดพลาดที่อธิบายได้** — ข้อผิดพลาดมาพร้อมสาเหตุและคำแนะนำที่นำไปปฏิบัติได้ ไม่ใช่รหัสดิบ
- **ข้อมูลที่พกพาได้** — ส่งออกและนำเข้าได้ในคลิกเดียว ย้ายเครื่องด้วยไฟล์เดียว
- **ใช้คีย์บอร์ดเป็นหลัก** — ทุกการทำงานหลักมีคีย์ลัด

## ฟีเจอร์

### ศูนย์รวมทรัพย์สิน
- เลย์เอาต์แบบตารางและแบบกริด ค้นหาครอบคลุมชื่อ โฮสต์ กลุ่ม เจ้าของ และบันทึก
- รายการโปรด การเชื่อมต่อล่าสุด และกลุ่มที่ย่อ/ขยายได้ในแถบด้านข้าง
- แสดง/ซ่อนแต่ละคอลัมน์และจัดลำดับใหม่ พร้อมขนาดฟอนต์ของรายการทั้งระบบ
- การแจ้งเตือนการหมดอายุ: ทรัพย์สินที่จะหมดอายุภายใน 30 วัน (หรือหมดอายุแล้ว) จะถูกทำเครื่องหมายไว้ตรงนั้น
- ตรวจหาข้อมูลซ้ำด้วย **host + port** ขณะนำเข้า

### RDP / SSH / VNC
- พอร์ตเริ่มต้นตามโปรโตคอล (3389 / 22 / 5900) และแก้ไขทับได้อย่างอิสระ
- **RDP** — สร้างไฟล์ `.rdp` ชั่วคราวสำหรับ Microsoft Windows App; โหมดหน้าต่าง ความลึกสี
  การส่งผ่านไดรฟ์/เสียง/คลิปบอร์ด และความละเอียด กำหนดค่าได้ทั้งหมด ระบบจะตรวจพบไบนารี FreeRDP
  แล้วเปิดใช้งานพร้อมรหัสผ่านที่บันทึกไว้โดยตรง ข้ามพรอมป์ขอข้อมูลรับรองไป
  การเติมรหัสผ่านอัตโนมัติในไดอะล็อกข้อมูลรับรองของ Windows App ใช้ macOS Accessibility API
- **VNC** — ใช้ Screen Sharing ที่มีมาให้เป็นค่าเริ่มต้น; โปรแกรมดูภายนอก (RealVNC, TigerVNC…)
  กำหนดค่าด้วยเทมเพลตอาร์กิวเมนต์สำหรับเปิดโปรแกรมที่รองรับ
  `{host} {port} {display} {user} {password}`
- **SSH** — เทอร์มินัลจริงที่ฝังอยู่ในแอป (SwiftTerm) รองรับ jump host (`-J`) การยืนยันตัวตนด้วยคีย์ส่วนตัว
  การรองรับ passphrase ของคีย์ และอาร์กิวเมนต์ `ssh` เพิ่มเติมที่กำหนดค่าได้

### เทมเพลตการเชื่อมต่อ
ชุดพารามิเตอร์ที่ใช้ซ้ำได้ (โปรโตคอล พอร์ต ชื่อผู้ใช้ การส่งผ่าน โหมดหน้าต่าง ความลึกสี
ขนาดหน้าต่าง SSH) พารามิเตอร์ที่ถูก resolve แล้วทุกตัวจะแสดงค่าปัจจุบัน **และที่มาของค่านั้น**

### พื้นที่ทำงานของเซสชัน
- หลายเซสชันวางเคียงกัน พร้อมเลย์เอาต์แบบแบ่งหน้าจอที่สลับได้ และขยายเต็มจอเป็นรายเซสชัน
- กล่อง "เปิดทรัพย์สิน" บนแถบเครื่องมือ: พิมพ์ชื่อหรือโฮสต์แล้วกด Return หรือเลือกจากรายการ
- รองรับหน้าต่าง SSH แยกต่างหาก เมื่อคุณต้องการให้อยู่นอกพื้นที่ทำงาน

### การถ่ายโอนไฟล์ SFTP
- ตัวเรียกดูไฟล์ระยะไกลแบบเต็มรูปแบบต่อทรัพย์สิน: ไดเรกทอรี ขนาด สิทธิ์ และเวลาที่แก้ไข
- อัปโหลดและดาวน์โหลดไฟล์หรือทั้งโฟลเดอร์ พร้อมทำงานต่อจากเดิม (`reput` / `reget`)
- สร้างโฟลเดอร์ ลบไฟล์หรือโฟลเดอร์ว่าง และลากไฟล์วางลงในโฟลเดอร์ปัจจุบัน
- เข้าใช้งานได้จากแถบเครื่องมือของเซสชันและจากเมนูคลิกขวาของเทอร์มินัล SSH

### เมนูคลิกขวาของเทอร์มินัล SSH
คัดลอก วาง เลือกทั้งหมด และ "ถ่ายโอนไฟล์" ตรงจุดที่คุณกำลังพิมพ์ เมื่อโปรแกรมระยะไกล
จับเมาส์ไว้ (vim, tmux) การคลิกขวาจะถูกส่งต่อไปยังโปรแกรมระยะไกลตามที่คาดไว้

### ข้อมูลรับรอง
- รหัสผ่านและ passphrase ของคีย์ถูกจัดเก็บ **ไว้ใน** macOS Keychain เท่านั้น ไม่เคยอยู่ในไฟล์ข้อมูล
- การลบทรัพย์สินหรือยกเลิกการเลือก "จดจำรหัสผ่าน" จะลบรายการใน Keychain ออก

### การนำเข้า ส่งออก และซิงค์
- นำเข้าจาก CSV หรือ Excel (`.xlsx`) พร้อมการจับคู่คอลัมน์อัตโนมัติและตัวอย่างก่อนตรวจสอบความถูกต้อง
- ส่งออกเป็น CSV หรือ JSON เลือกได้เป็นรายฟิลด์; ฟิลด์ที่ละเอียดอ่อนจะไม่ถูกเลือกไว้เป็นค่าเริ่มต้น
- การซิงค์บนคลาวด์จะดึงตัวอย่างมาก่อน แล้วรวมเฉพาะสิ่งที่คุณเลือก — เฉพาะทรัพย์สินและเทมเพลต
  ไม่มีรหัสผ่านเด็ดขาด

### การตรวจสอบการเข้าถึง
การตรวจสอบ TCP ของทรัพย์สินเดี่ยว รายการที่เลือก หรือทั้งคลัง ตามต้องการหรือตามเวลาที่ตั้งไว้

### การล็อกแอป (passphrase ป้องกัน)
- การล็อกด้วย passphrase แบบเลือกได้ พร้อมการล็อกอัตโนมัติเมื่อไม่มีการใช้งาน (1–60 นาที)
- การแฮช passphrase ด้วย **PBKDF2-SHA256** จำนวน 100 000 รอบ และ salt แบบสุ่มขนาด 128 บิต
- รหัสกู้คืนจะออกให้ครั้งเดียวตอนตั้งค่า (Crockford Base32 รองรับความสับสนของ `O/0`, `I/L/1`)
- กำหนดค่าได้: หลังจากป้อนผิดติดต่อกัน 5 ครั้ง จะล้างข้อมูลภายในเครื่องโดยอัตโนมัติ หรือคงสถานะล็อกไว้และ
  ให้ล้างด้วยตนเอง

### รูปลักษณ์และความช่วยเหลือ
- ธีมตามระบบ / สว่าง / มืด; อินเทอร์เฟซภาษาจีนตัวย่อและภาษาอังกฤษ
- คู่มือช่วยเหลือในแอป ครอบคลุมการใช้งาน VNC การแก้ปัญหาตามโปรโตคอล ตำแหน่งของข้อมูล และ
  ความเป็นส่วนตัวของข้อมูลรับรอง

## ความต้องการของระบบ

| รายการ | ความต้องการ |
| --- | --- |
| macOS | 14.0 (Sonoma) หรือใหม่กว่า |
| โปรแกรมรองรับ RDP | Microsoft Windows App (จาก App Store) |
| โปรแกรมรองรับ VNC | Screen Sharing ที่มีมาให้ หรือ RealVNC / TigerVNC และอื่น ๆ ที่คล้ายกัน |
| การเติมรหัสผ่าน RDP อัตโนมัติ | สิทธิ์ Accessibility สำหรับ OpenNodeDesk |
| การบิลด์จากซอร์ส | Xcode 16 หรือใหม่กว่า (Swift 6 toolchain) |

## การติดตั้ง

1. ดาวน์โหลด `OpenNodeDesk-<version>-macos.zip` จากหน้า
   [Releases](https://github.com/OpenNodeSaas/OpenNodeDesk-macos/releases)
2. แตกไฟล์แล้วลาก `OpenNodeDesk.app` ไปไว้ใน `/Applications`
3. บิลด์นี้ยังไม่ผ่านการรับรองจาก Apple ดังนั้น Gatekeeper อาจเตือนในครั้งแรกที่เปิด — คลิกขวาที่
   แอปแล้วเลือก **Open** หรืออนุญาตใน *System Settings → Privacy & Security*

## การบิลด์จากซอร์ส

```bash
git clone https://github.com/OpenNodeSaas/OpenNodeDesk-macos.git
cd OpenNodeDesk-macos
make bundle   # release build + dist/OpenNodeDesk.app
make run      # build, bundle and launch
```

เป้าหมายที่มีประโยชน์: `make check` (คอมไพล์และแสดงไดแอกโนสติกส์), `make clean` (ลบ `.build` และ
`dist`), `make reset` (ลบข้อมูลภายในเครื่องจาก `~/Library/Application Support/RemotePilot`)

## โครงสร้างโปรเจกต์

```
Sources/RemotePilot/
├── App/            จุดเริ่มต้นของแอป โมเดลส่วนกลาง คำสั่ง และเมนู
├── Core/           SSH/SFTP, Keychain, การตรวจสอบ, นำเข้า/ส่งออก, การซิงค์, การตรวจจับโปรแกรมรองรับ, การเติมอัตโนมัติของ RDP
├── Design/         โทเคนการออกแบบและคอมโพเนนต์ที่ใช้ร่วมกัน
├── Localization/   สตริงต้นทางภาษาจีน + ตารางสตริงภาษาอังกฤษ
├── Models/         โมเดล Asset, template, settings และ runtime
├── Views/          แถบด้านข้าง, ศูนย์รวมทรัพย์สิน, พื้นที่ทำงาน, เซสชัน, การตั้งค่า, ความช่วยเหลือ, ไดอะล็อก
└── main.swift      จุดเริ่มต้น (ทำหน้าที่เป็นตัวช่วย SSH_ASKPASS ด้วย)
Resources/          Info.plist และไอคอนแอป
docs/              เอกสารการออกแบบและ README ฉบับแปล
```

## ข้อมูลและความเป็นส่วนตัว

- ทรัพย์สิน เทมเพลต และการตั้งค่าอยู่ใน `~/Library/Application Support/RemotePilot`
  (`assets.json`, `settings.json`)
- รหัสผ่านและ passphrase ของคีย์ถูกเขียนไว้ใน macOS Keychain เท่านั้น; ไม่เคยเป็นส่วนหนึ่งของ
  ข้อมูลส่งออกหรือเพย์โหลดการซิงค์ ดังนั้นการย้ายไปเครื่องอื่นจึงต้องป้อนใหม่
- แอปทำงานแบบออฟไลน์ได้เต็มที่; ปลายทางการซิงค์บนคลาวด์เป็นตัวเลือกและผู้ใช้เป็นผู้กำหนดเอง

## หมายเหตุและข้อจำกัด

- Windows App ของ macOS ไม่สามารถเปิดหลายเซสชันเป็นแท็บในหน้าต่างเดียวได้; การเลือกโหมดหน้าต่าง
  แบบแท็บจะเปิดเป็นหน้าต่างปกติแทน ใช้พื้นที่ทำงานของเซสชันสำหรับหลายเซสชัน
- หากยังไม่ได้ติดตั้งโปรแกรมรองรับ RDP เมื่อพยายามเชื่อมต่อ ระบบจะอธิบายว่าต้องติดตั้งอะไรและที่ไหน
- ตัวระบุบันเดิลภายใน `com.remotepilot.macos` และไดเรกทอรีข้อมูล
  `RemotePilot` ถูกตั้งใจให้ไม่เปลี่ยนแปลงตั้งแต่เปลี่ยนชื่อ เพื่อให้ทรัพย์สิน การตั้งค่า และ
  รายการใน Keychain ที่มีอยู่เดิมยังใช้งานได้หลังอัปเกรด
