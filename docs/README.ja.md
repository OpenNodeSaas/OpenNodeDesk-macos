# OpenNodeDesk for macOS

**macOS 向けのローカルファーストなリモート接続ハブ。** あらゆるサーバー、アカウント、接続
パラメータを、検索可能で再利用でき、持ち運べるひとつのリストにまとめます — そして
「あのマシンが必要」からライブセッションまでを 3 ステップで実現します。

## これは何か

OpenNodeDesk は、もうひとつのリモートデスクトップクライアントではありません。リモート画面の
描画、周辺機器のリダイレクト、オーディオ/ビデオは、プラットフォーム上で最も成熟したクライアントに
任せます — RDP なら Microsoft Windows App、VNC なら標準搭載の Screen Sharing、SSH なら内蔵
ターミナルです。OpenNodeDesk が担うのは**残りの 90%**、すなわちインベントリ、パラメータ、
認証情報、有効期限のリマインダー、そして接続履歴です。

設計原則:

- **3 秒で接続** — 検索し、Return キーを押すと、セッションが開きます。
- **ローカルファースト、オフライン対応、アカウント不要** — ネットワークなしで開く、検索する、編集する、接続する。
- **車輪の再発明はしない** — リモート描画はプラットフォーム最高のクライアントに任せます。
- **説明可能なパラメータ** — 有効なすべての値には *custom / template / default* のラベルが付きます。
- **説明可能な失敗** — エラーには原因と実行可能な提案が添えられ、生のコードだけが表示されることはありません。
- **持ち運べるデータ** — ワンクリックでエクスポートとインポート。ひとつのファイルでマシンを移行できます。
- **キーボード優先** — すべての主要な操作にショートカットがあります。

## 機能

### アセットセンター
- テーブル表示とグリッド表示。名前、ホスト、グループ、所有者、メモを横断して検索できます。
- サイドバーにはお気に入り、最近の接続、折りたたみ可能なグループがあります。
- 列ごとの表示/非表示と並べ替え、さらにリスト全体のフォントサイズを設定できます。
- 有効期限のリマインダー: 30 日以内に期限切れになる (またはすでに期限切れの) アセットはその場でフラグが立ちます。
- インポート時に **host + port** による重複検出を行います。

### RDP / SSH / VNC
- プロトコルごとのデフォルトポート (3389 / 22 / 5900) を自由に上書きできます。
- **RDP** — Microsoft Windows App 用の一時的な `.rdp` ファイルを生成します。ウィンドウモード、色
  深度、ドライブ/オーディオ/クリップボードのリダイレクト、解像度はすべて設定できます。FreeRDP の
  バイナリが検出されると、保存済みのパスワードで直接起動し、認証情報の入力プロンプトをスキップします。
  Windows App の認証情報ダイアログへのパスワード自動入力には、macOS の Accessibility API を使用します。
- **VNC** — デフォルトでは標準搭載の Screen Sharing を使用します。外部ビューア (RealVNC、TigerVNC など)
  は、`{host} {port} {display} {user} {password}` をサポートする起動引数テンプレートで設定できます。
- **SSH** — アプリに組み込まれた本物のターミナル (SwiftTerm)。ジャンプホスト (`-J`)、秘密鍵
  認証、鍵のパスフレーズ対応、追加の `ssh` 引数を設定できます。

### 接続テンプレート
再利用可能なパラメータセット (プロトコル、ポート、ユーザー名、リダイレクト、ウィンドウモード、色深度、SSH
ウィンドウサイズ)。解決されたすべてのパラメータは、現在の値と**その由来**を表示します。

### セッションワークスペース
- 複数のセッションを並べて表示し、切り替え可能な分割レイアウト、セッションごとの最大化に対応します。
- ツールバーの「アセットを開く」ボックス: 名前またはホストを入力して Return キーを押すか、リストから選択します。
- ワークスペースから切り離したい場合は、独立した SSH ウィンドウも利用できます。

### SFTP ファイル転送
- アセットごとの完全なリモートファイルブラウザ: ディレクトリ、サイズ、パーミッション、更新日時。
- ファイルまたはフォルダ全体のアップロードとダウンロード。レジューム機能 (`reput` / `reget`) 付き。
- フォルダの作成、ファイルまたは空フォルダの削除、現在のフォルダへのファイルのドラッグ＆ドロップ。
- セッションツールバーと SSH ターミナルのコンテキストメニューから利用できます。

### SSH ターミナルのコンテキストメニュー
入力中のその場で、コピー、貼り付け、すべて選択、「ファイル転送」が行えます。リモートプログラムが
マウスをキャプチャしている場合 (vim、tmux)、右クリックは想定どおりリモートプログラムへそのまま渡されます。

### 認証情報
- パスワードと鍵のパスフレーズは macOS の Keychain に**のみ**保存され、データファイルに書き込まれることはありません。
- アセットを削除するか「パスワードを保存」のチェックを外すと、Keychain のエントリが削除されます。

### インポート、エクスポート、同期
- CSV または Excel (`.xlsx`) からのインポート。自動列マッピングと検証プレビュー付き。
- CSV または JSON へのエクスポート。フィールド単位で選択でき、機密フィールドはデフォルトでチェックが外れています。
- クラウド同期はまずプレビューを取得し、選択したものだけをマージします — 対象はアセットとテンプレートのみで、
  パスワードは決して含まれません。

### 到達性のプロービング
単一のアセット、選択範囲、またはインベントリ全体に対して、オンデマンドまたはタイマーで TCP プロービングを実行します。

### アプリロック (保護パスフレーズ)
- オプションのパスフレーズロックと、アイドル時の自動ロック (1～60 分)。
- パスフレーズのハッシュ化には **PBKDF2-SHA256**、100,000 回のイテレーション、ランダムな 128 ビットソルトを使用します。
- セットアップ時に復旧コードが一度だけ発行されます (Crockford Base32、`O/0`、`I/L/1` を許容)。
- 設定可能: 5 回連続で失敗した後、ローカルデータを自動的に消去するか、ロックを維持して
  手動消去を要求するかを選べます。

### 外観とヘルプ
- システム連動 / ライト / ダークのテーマ。インターフェイスは簡体字中国語と英語。
- VNC の使い方、プロトコルごとのトラブルシューティング、データの保存場所、認証情報のプライバシーを扱う
  アプリ内ヘルプマニュアル。

## 動作要件

| 項目 | 要件 |
| --- | --- |
| macOS | 14.0 (Sonoma) 以降 |
| RDP キャリア | Microsoft Windows App (App Store から) |
| VNC キャリア | 標準搭載の Screen Sharing、または RealVNC / TigerVNC など |
| RDP パスワードの自動入力 | OpenNodeDesk に対する Accessibility 権限 |
| ソースからのビルド | Xcode 16 以降 (Swift 6 ツールチェーン) |

## インストール

1. [Releases](https://github.com/OpenNodeSaas/OpenNodeDesk-macos/releases) ページから
   `OpenNodeDesk-<version>-macos.zip` をダウンロードします。
2. 解凍して `OpenNodeDesk.app` を `/Applications` にドラッグします。
3. このビルドは Apple による公証を受けていないため、初回起動時に Gatekeeper が警告を表示する場合があります —
   アプリを右クリックして**開く**を選択するか、*システム設定 → プライバシーとセキュリティ* で許可してください。

## ソースからのビルド

```bash
git clone https://github.com/OpenNodeSaas/OpenNodeDesk-macos.git
cd OpenNodeDesk-macos
make bundle   # release build + dist/OpenNodeDesk.app
make run      # build, bundle and launch
```

便利なターゲット: `make check` (コンパイルして診断を表示)、`make clean` (`.build` と
`dist` を削除)、`make reset` (`~/Library/Application Support/RemotePilot` からローカルデータを削除)。

## プロジェクト構成

```
Sources/RemotePilot/
├── App/            アプリのエントリポイント、グローバルモデル、コマンドとメニュー
├── Core/           SSH/SFTP、Keychain、プロービング、インポート/エクスポート、同期、キャリア検出、RDP 自動入力
├── Design/         デザイントークンと共有コンポーネント
├── Localization/   中国語のソース文字列 + 英語の文字列テーブル
├── Models/         アセット、テンプレート、設定、ランタイムモデル

└── main.swift      エントリポイント (SSH_ASKPASS ヘルパーも兼ねる)
Resources/          Info.plist とアプリアイコン
docs/              設計ドキュメントと翻訳済み README
```

## データとプライバシー

- アセット、テンプレート、設定は `~/Library/Application Support/RemotePilot`
  (`assets.json`、`settings.json`) に保存されます。
- パスワードと鍵のパスフレーズは macOS の Keychain にのみ書き込まれ、エクスポートや
  同期ペイロードに含まれることはありません。そのため、別のマシンへ移行する際は再入力が必要です。
- アプリは完全にオフラインで動作します。クラウド同期のエンドポイントはオプションで、ユーザーが指定します。

## 注意事項と制限

- macOS の Windows App は、複数のセッションをひとつのウィンドウのタブとしてホストできません。タブ付き
  ウィンドウモードを選択すると、代わりに通常のウィンドウが開きます。複数のセッションにはセッションワークスペースを使用してください。
- RDP キャリアがインストールされていない場合、接続を試みると何をどこにインストールすべきかが説明されます。
- 内部のバンドル識別子 `com.remotepilot.macos` とデータディレクトリ
  `RemotePilot` は、改名以降も意図的に変更されていないため、既存のアセット、設定、
  Keychain エントリはアップグレード後もそのまま機能します。
