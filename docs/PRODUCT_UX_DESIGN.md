## 1. 产品定位与设计原则

### 1.1 定位

面向运维/IT 人员的**个人远程连接中枢**：把散落在各处的服务器、账号、连接参数、到期信息、连接历史集中成一份可搜索、可复用、可迁移的资产清单，并把「找到机器 → 建立连接」压缩到最少步骤。

它不替代远程客户端本身。远程画面的画质、外设重定向、音视频能力**跟随各平台最成熟的官方客户端**——Windows 用系统远程桌面，macOS 用 Microsoft Windows App，Linux 用系统首选客户端。RemotePilot 负责的是**前面那 90% 的准备与管理工作**。

### 1.2 体验至上：八条设计原则

1. **三秒发起连接**：从打开应用到进入会话，熟练用户不超过 3 步（搜索 → 回车 → 画面出现）。
2. **本地优先、离线可用、零账号**：无网络也能打开、搜索、编辑、发起连接；不强制登录。
3. **不重造轮子**：远程渲染交给平台最佳客户端，本产品专注资产与体验编排。
4. **渐进披露**：默认界面只呈现「连得上」所需信息，高级参数按需展开，不堆表单。
5. **参数可解释**：每个生效参数都标注「当前值 + 来源（自定义 / 模板 / 默认）」，用户永远知道为什么是这个值。
6. **失败可解释可恢复**：连接/探测失败时就地给出原因与可执行建议，并提供一键重试，而不是抛一句原始报错。
7. **数据可携带**：一键导出/导入，格式透明（含字段选择），换机迁移只需一个文件。
8. **键盘优先**：核心操作全部有快捷键，鼠标与键盘双通路等价。

### 1.3 体验红线（不可妥协）

- 任何一次「新建资产 → 连接」都不得要求用户填写协议专有参数以外的技术细节。
- 任何错误都不得只显示异常堆栈或原始错误码。
- 任何危险操作（导出密码、批量删除）都必须二次确认，且默认不勾选敏感项。
- 中文/English 切换必须即时全局生效，不需要重启。

## 2. 目标用户与核心场景

### 2.1 用户画像

| 画像 | 特征 | 核心诉求 |
| --- | --- | --- |
| 运维工程师（主力） | 管理 20–500 台机器，多协议混用（RDP/SSH/VNC） | 快速定位、批量操作、少输密码 |
| 外包/驻场工程师 | 频繁切换不同客户网络，机器多为临时 | 快速建连、配置可带走 |
| 团队负责人 | 关心资产归属与凭证到期 | 到期预警、按负责人/分组盘点 |

### 2.2 核心场景（Jobs to be Done）

1. **我要连上一台机器**：已知名字或 IP，用最短路径进入会话。
2. **我又要连同一批机器**：它们共享一套连接参数，我不想每次重填。
3. **我要把一批机器一次性录进来**：手里有 Excel/CSV 清单。
4. **我要同时看几台机器**：并排分屏，边操作边对照。
5. **我要知道哪些凭证快过期了**：一眼看到预警，按负责人/分组排查。
6. **我要连不上了想搞清楚为什么**：就地得到原因与排查建议。
7. **我要换台电脑继续用**：整份资产与配置搬过去。
8. **我遇到不会用的地方**：在应用内就能查说明，不用去外面搜。

## 3. 功能架构

### 3.1 信息架构（导航）

左侧导航（可收起为图标条）自上而下：

| 区域 | 入口 | 说明 |
| --- | --- | --- |
| 品牌区 | Logo + 产品名 + 版本 | 点击回首页 |
| 主导航 | 资产中心 / 会话工作台 / 收藏列表 / 最近使用 | 四大常用视图 |
| 分组 | 服务器分组（可展开内联列出全部分组） | 展开后直接点分组名进入过滤视图 |
| 帮助 | 帮助手册 | 应用内文档与参数说明 |
| 底部工具 | 主题切换 / 语言切换 / 意见反馈 | 常驻可见 |

收起态：仅保留图标列，悬停即展开；展开状态被记住。收起/展开入口在品牌区右侧。

## 4. 界面规格（UI Spec）

### 4.1 主窗口布局

```
┌─────────┬───────────────────────────────────────────────────┬──────────────┐
│ 左侧导航 │ 顶部命令栏（搜索 | 视图切换 | 新增/打开/抽屉/导入导出）│  右侧详情面板 │
│ (可收起) ├───────────────────────────────────────────────────┤  (可折叠)     │
│         │ 参数栏（窗口模式 | 重定向 | 色深 | 探测）             │              │
│         ├───────────────────────────────────────────────────┤  分辨率快配   │
│         │ 分组徽章 + 到期汇总                                 │  到期/探测卡  │
│         ├───────────────────────────────────────────────────┤  就地诊断     │
│         │ 内容区：表格 / 卡片 / 会话工作台 / 帮助手册           │              │
│         ├───────────────────────────────────────────────────┤              │
│         │ 状态栏                                              │  快捷保存     │
└─────────┴───────────────────────────────────────────────────┴──────────────┘
```

- 窗口最小尺寸以「表格 12 列不横向滚动」为基准；右侧面板默认收起，选中资产时按需展开。
- 三块区域宽度均可调；左侧可完全收起，右侧可完全收起（宽度 0）。

### 4.2 左侧导航规格

- 单项高度与内边距保证触控友好（不低于 40px 命中区）。
- 当前项高亮：浅色底 + 左侧主色竖条（选中态优先于任何预警色）。
- 分组项展开时，子分组缩进列出，点击即过滤资产列表，不打开新窗口。
- 语言/主题/反馈常驻底部，任何视图下都可一键切换。

### 4.3 顶部命令栏规格

三层，每层职责单一：

**第一层（主命令）**
- 全局搜索框（宽度足够容纳典型关键词；回车触发；有清空按钮）。
- 视图切换：表格 / 宫格（分段控件，当前态填充主色）。
- 主操作：新增资产（主色实心按钮，视觉最重）。
- 次要操作：打开、连接方案抽屉、导入、导出选中、反选、删除、云端同步。
- 选中计数实时显示在删除按钮旁，为 0 时删除按钮置灰。

**第二层（连接参数，作用于「下一次连接」）**
- 窗口模式：普通 / 全屏 / 小窗 / 标签（单选）。
- 设备重定向：驱动器映射 / 音频 / 剪贴板（多选，带统一能力提示 Tooltip）。
- 色深：8/15/16/24/32（下拉）。
- 探测按钮：对选中/全部发起可达性检测。

**第三层（概览与预警）**
- 分组徽章：每个分组一枚徽章，显示分组名 + 机器数，点击即过滤。
- 批量探测按钮。
- 到期预警汇总条（有预警时才出现，琥珀色，点击展开明细列表）。

### 4.4 表格视图规格

列顺序（从左到右）：

| # | 列 | 交互 | 排序 |
| --- | --- | --- | --- |
| 1 | 收藏 | 单击切换星标 | - |
| 2 | 选择 | 单元格复选；表头三态（全选/半选/全不选） | - |
| 3 | 分组 | 只读 | 支持 |
| 4 | 负责人 | 只读 | 支持 |
| 5 | 名称 | 只读 | 支持 |
| 6 | IP:端口 | 只读，弱化色 | 支持 |
| 7 | 用户名 | 只读 | 支持 |
| 8 | 状态 | 彩色徽章（可达=绿 / 不可达=红 / 未检测=灰） | 支持 |
| 9 | 到期日 | 只读 | 支持 |
| 10-12 | 备注 1/2/3 | 只读 | 支持 |
| 13 | 模板 | 主色下划线链接，点击打开连接方案抽屉 | 支持 |
| 14 | 协议 | 只读（rdp/ssh/vnc） | 支持 |
| 15 | 操作 | 编辑 / 删除 | - |

约定：
- 除操作列外**所有列均可排序**，点击表头切换升降序并显示指示箭头。
- 行高不低于 42px；斑马纹交替；到期临期行整行琥珀色底。
- 双击任意行 = 直接建立连接（不强制跳转工作台）。

### 4.5 卡片宫格视图规格

- 卡片固定宽度，流式换行；每张卡片含：名称、状态徽章、IP:端口、收藏星标、分组、负责人、到期日、快速连接按钮、编辑按钮。
- 卡片悬停轻微抬升（阴影/描边变化），点击星标不触发连接。
- 名称过长省略并保留完整 Tooltip。

### 4.6 会话工作台规格

**标签页栏**：每个会话一枚标签，含状态圆点、名称、关闭按钮；标签溢出横向滚动；`全部关闭` 常驻右侧。

**工具栏**：布局切换（单屏 / 1×2 / 2×1 / 2×2 / 2×3 / 3×3）、适应窗口、全屏、连接配置、断开当前（危险色）。

**单元格**：
- 顶栏：协议徽章（RDP/SSH/VNC 各自配色）、状态指示灯、名称与 `(主机:端口)`、最大化/还原、关闭。
- 内容区：
  - **SSH**：内嵌终端，键盘直接输入，选中复制。
  - **RDP / VNC**：显示**连接信息占位页**——目标地址、承载客户端名称、`打开窗口` 按钮；首次进入自动尝试拉起，成功后焦点交给外部客户端窗口。
- 焦点单元格有强调边框；点击单元格任意位置即聚焦，标签页同步高亮。

### 4.7 右侧详情面板规格

仅保留两类信息，其余编辑一律走资产编辑对话框（避免重复）：

1. **分辨率快速配置**：宽/高输入、`16:9` `16:10` 预设、左右/上下对分预设、恢复默认。
2. **只读状态卡**：到期预警状态、最后检测耗时。
3. **就地诊断卡**（连接/探测失败时出现）：原因 + 检查建议 + `重试`按钮。
4. 全局项：探测间隔（秒，0 = 关闭）、`记住密码`开关 + 说明文案。
5. 底部：`保存设置` 主按钮。

### 4.8 对话框规格

| 对话框 | 关键内容 | 体验要点 |
| --- | --- | --- |
| 资产编辑 | 名称、分组（可输入新建）、主机、端口（随协议给默认值）、协议、模板、用户名、密码、记住密码、SSH 密钥/口令/跳板机、负责人、到期日、备注×3、RDP 重定向 | 选协议即动态显隐相关字段；端口默认值随协议自动填充 |
| 模板编辑 | 名称、协议、端口、用户名、RDP 显示与重定向 | 仅 RDP 相关参数，切换协议即隐藏无关项 |
| 模板管理 | 左列表 + 右详情 + 新建/编辑/复制/删除 + 排序 | 未选中时编辑/复制/删除置灰 |
| 导出字段 | 字段多选（分两栏）、敏感字段红色标注、风险提示 | 密码 / SSH 密钥默认不勾选，勾选需确认 |
| 云端同步 | 服务地址、令牌、待导入预览（可勾选）、状态 | 预览先行，不直接落库 |
| SSH 凭据 | 用户名、密码、密钥路径、记住凭据 | 认证失败时弹出，避免死循环；输入后引导重连 |
| 意见反馈 | 邮件/仓库链接、可复制全文 | 无邮件客户端时给出可复制文本兜底 |

### 4.9 帮助手册规格

- 页首：标题 + 一句副标题（说明本手册覆盖范围）。
- **客户端配置卡**：客户端可执行文件路径（可浏览选择 / 自动探测）、启动参数模板、参数说明、`恢复默认参数`、`保存设置`；下方实时状态行（已就绪 / 未检测到 / 路径不存在）。
- 章节区（按当前语言动态生成）：
  1. VNC 使用说明（外装客户端如何选取、参数含义）
  2. VNC 常见疑点（密码传递、端口/display 编号、认证失败）
  3. RDP 常见疑点（未签名文件的安全弹窗、窗口标题来源、重定向为何没生效）
  4. SSH 常见疑点（跳板机、密钥口令、认证失败后如何重试）
  5. 通用说明（数据存放位置、迁移方式、隐私与凭据安全）

## 5. 关键交互流程（UE）

### 5.1 首次添加并连接（目标 3 步内）

```
新增资产 → 填写 名称/主机/协议（其余留空走默认）
        → 保存后自动选中
        → 双击行 或 回车 → 建立连接
```

- 协议默认 RDP；端口随协议自动给默认值（RDP 3389 / SSH 22 / VNC 5900）。
- 保存即校验：主机为空、端口非法时，在字段旁就地红字提示，不弹窗。

### 5.2 用模板批量复用

```
模板管理 新建模板（如「生产机-全屏-开启剪贴板」）
→ 资产编辑里选择该模板
→ 连接时自动套用；需要临时改时打开连接方案抽屉覆盖
```

- 抽屉顶部显示「参数来源：模板 / 自定义」，覆盖后变为自定义。
- 抽屉底部「当前生效参数预览」逐一列出参数值与来源，避免「不知道到底生效了什么」。

### 5.3 批量导入

```
导入 → 选择 CSV/Excel → 字段映射/预览 → 确认导入 → 列表刷新 + 结果摘要
```

- 导入结果明确告知成功/失败条数与失败原因，失败行可导出。
- 协议列原样保留，识别到 ssh/vnc 的行自动按对应协议处理。

### 5.4 多会话分屏

```
资产 A 双击 → 标签 A
资产 B 双击 → 标签 B（不切走工作台）
切到工作台 → 选择 2×2 → 拖拽/自动填充单元格
```

- 单元格最大化后，布局按钮区域仍可见，便于还原。
- 关闭单元格只关闭该会话；`全部关闭` 需确认。

### 5.5 连接/探测失败的恢复路径

```
失败 → 状态栏提示 + 详情面板出现诊断卡（原因 + 建议）→ 点击「重试」
```

- 可达性探测与真实建连区分：探测失败 ≠ 不能连（可能只屏蔽了 ICMP/端口探测），文案明确区分。

### 5.6 VNC 首次配置（外装客户端）

```
双击 VNC 资产 → 未检测到客户端 → 提示 + 指引到帮助手册
→ 帮助手册填写/探测客户端路径 → 保存
→ 回到资产重新连接 → 自动拉起客户端窗口
```

- 已配置但路径失效时，同样给出「路径不存在」的明确提示与修改入口。

### 5.7 键盘与快捷键约定

| 快捷键 | 动作 |
| --- | --- |
| `Ctrl+K` | 聚焦全局搜索 |
| `Enter`（列表聚焦时） | 对选中项建立连接 |
| `Esc` | 关闭抽屉 / 取消对话框 |
| `Ctrl+S`（抽屉/详情面板） | 保存当前设置 |
| `Ctrl+W` | 关闭当前会话标签 |
| `Tab / Shift+Tab` | 表单内顺序切换 |

## 6. 状态与反馈规范

| 类型 | 呈现位置 | 时长/行为 |
| --- | --- | --- |
| 成功（连接已发起、已保存、已导入） | 底部状态栏 + 可选轻提示 | 常驻至下一操作 |
| 进行中（探测/同步/导入） | 按钮进入加载态 + 状态栏文案 | 完成后自动恢复 |
| 可恢复错误（连接失败、路径失效） | 详情面板诊断卡 + 状态栏 | 直到用户处理或重试成功 |
| 阻断错误（数据写入失败） | 模态提示 + 明确下一步 | 需用户确认 |
| 危险操作 | 模态二次确认，敏感项默认不勾选 | 需显式确认 |
| 空状态 | 内容区居中说明 + 主操作按钮 | 引导下一步 |

状态徽章配色语义固定：绿=正常/可达，红=异常/不可达，灰=未知/未检测，琥珀=临期预警。

## 7. 视觉规范（Design Tokens）

所有颜色、圆角、间距以「主题令牌」形式定义，浅色/深色两套，切换即时生效。

### 7.1 色板（语义化）

| 令牌 | 语义 | 浅色示例 |
| --- | --- | --- |
| AppBackground | 窗口底色 | 浅灰 |
| SurfaceBackground | 卡片/面板底 | 白 |
| SidebarBackground | 导航/次级面板 | 更浅灰 |
| CardBackground | 卡片底 | 白 |
| Primary | 主色/强调/链接 | 蓝 |
| Success / Warning / Danger | 状态语义色 | 绿 / 琥珀 / 红 |

| DataGridRowAlternate | 斑马纹 | 极浅灰 |
| ExpiryRowWarnBackground | 临期行底 | 浅琥珀 |

### 7.2 字体与排版

- 界面字体：各平台系统 UI 字体（Windows: Segoe UI，macOS: SF Pro，Linux: 发行版默认无衬线）。
- 层级：标题 20 / 区块标题 14–16 / 正文 12–13 / 辅助说明 11。
- 数字与地址建议使用等宽字体，便于比对 IP 与端口。

### 7.3 间距与形状

- 基础间距单位 4px；常用 4 / 6 / 8 / 12 / 16 / 24。
- 圆角：控件 4px，卡片/面板 6–8px。
- 描边统一 1px；选中态用 3px 主色竖条而非粗边框。

### 7.4 动效

- 面板/抽屉进出 150–200ms 缓动；不做花哨动画。
- 悬停反馈即时（≤80ms）。
- 尊重系统「减少动态效果」设置，开启时取消非必要动画。

## 8. 多平台体验策略

同一套信息架构与交互模型，各平台只替换「远程画面承载方」与少量系统集成点。**用户心智一致，能力跟随平台最佳客户端。**

| 能力 | Windows | macOS | Linux |
| --- | --- | --- | --- |
| RDP 画面承载 | 系统远程桌面客户端 | Microsoft **Windows App**（原 Microsoft Remote Desktop） | 系统首选 RDP 客户端（如 FreeRDP 系） |
| VNC 画面承载 | 外装 VNC 客户端（如 TightVNC / UltraVNC） | 外装 VNC 客户端（如 RealVNC / TigerVNC） | 外装 VNC 客户端（如 TigerVNC / Remmina） |
| SSH | 应用内终端 | 应用内终端 | 应用内终端 |
| 免密登录 | 可用（记住密码由系统账户级加密保护） | **降级为客户端内首次输入后由其自身记忆**（macOS 侧凭据由系统钥匙串保存） | 视所选客户端能力，通常支持命令行传参 |
| 驱动/剪贴板重定向 | 由系统客户端完整支持 | 由 Windows App 支持，部分项需在客户端内配置 | 视所选客户端能力 |
| 文件关联（双击 .rdp 等） | 支持 | 由系统客户端注册处理 | 视环境 |

体验约定：

- **不承诺跨平台完全等价**：文档与界面中明确标注「本平台差异」，让用户预期一致。
- **凭据安全跟随平台**：Windows 用系统账户级加密，macOS 用系统钥匙串，Linux 视发行版；跨机迁移时明确提示密码需重新输入。
- **能力探测而非硬编码**：界面永远先「探测本机可用的承载客户端」，探测不到时给出安装/指定路径的引导，而非直接报错。
- **平台专属入口统一收口在「帮助手册」**：不同平台的客户端选择与注意事项，在同一页面按当前系统展示，用户不必去外部搜索。

## 9. 无障碍与国际化

- **键盘可达**：所有交互控件可 Tab 抵达，焦点有清晰可见的轮廓。
- **语义标注**：图标按钮提供可被读屏识别的名称，状态不只靠颜色区分（徽章同时带文字）。
- **对比度**：正文文字与背景对比度不低于 4.5:1；状态色同时辅以文字标签。
- **缩放友好**：界面支持系统级缩放，不出现文字截断导致信息丢失（关键字段保留 Tooltip）。
- **国际化**：中英双语，键值集中管理；切换语言即时全局生效，含动态生成的章节正文；日期与数字格式随后续扩展可本地化。
- **文案克制**：面向运维人员，术语准确（可达性、重定向、跳板机、密钥口令），不口语化、不卖萌。

## 10. 体验验收标准

| # | 验收项 | 通过标准 |
| --- | --- | --- |
| 1 | 最短建连路径 | 已录入资产从打开应用到发起连接 ≤ 3 步 |
| 2 | 列表可用性 | 除操作列外所有列可排序；双击即连，不强制跳转 |
| 3 | 参数可解释 | 连接方案抽屉能显示每个生效参数的「值 + 来源」 |
| 4 | 失败可恢复 | 任一连接/探测失败路径都有原因 + 建议 + 重试入口 |
| 5 | 数据可携带 | 导出可选字段；导入有预览与结果摘要；敏感项默认不导出 |
| 6 | 危险操作防护 | 导出密码、批量删除均需二次确认且默认安全 |
| 7 | 多会话 | 支持 6 种布局；单元格可最大化/还原；标签状态灯准确 |
| 8 | 三协议一致 | RDP/SSH/VNC 在添加、连接、工作台、帮助四条链路体验一致 |
| 9 | 外装客户端 | 未检测到客户端时给出明确引导；配置后可一键拉起 |
| 10 | 国际化 | 中英切换即时生效，无残留旧语种文案 |
| 11 | 离线可用 | 断网下可打开、检索、编辑、发起本地连接 |
| 12 | 帮助自足 | 应用内帮助能覆盖各协议常见疑点，无需外部搜索 |
