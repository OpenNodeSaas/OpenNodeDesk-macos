## 2. 导航与信息架构（基线 §3.1）

- **主导航**：在「分组」之后依次新增两项：
  - **连接方案模板**（🧩）：进入模板管理视图（左列表 + 右详情的既有布局，见基线 §4.8）。
  - **设置**（⚙）：进入新增的「设置」页（见 §7）。
- **底部工具区**：主题切换 / 语言切换 / 意见反馈 保持基线不变，仍为常驻两列 + 一行布局。
- **品牌区**：Logo + `RemotePilot` 主标题保持不变，副标题显示 `RemoteOps v2.0`（运行版本标识）。
- **收起态**：仍为「保留图标列 + 悬停展开」，收起/展开入口位于品牌区右侧，与基线一致。

## 3. 顶部命令栏与资产列表（基线 §4.3 / §4.4）

### 3.1 命令栏（第一层）

- **移除**：顶栏的「连接方案」入口。配置入口统一收敛到列表「模板」列（点击打开连接方案抽屉）。
- **新增**：
  - 「列设置」按钮：打开列设置浮层（见 3.3）。
  - 「资产详情」按钮：位于第三层工具区「批量检测」右侧，用于手动展开/收起右侧详情面板。
- **视图切换**：保持「表格 / 宫格」两态（当前态填充主色）。
- **选中计数 + 删除置灰**：与基线一致。

### 3.2 参数栏（第二层，作用于「下一次连接」）

- 窗口模式、设备重定向、色深、探测按钮保持基线不变。
- **修改**：剪贴板选项文案由「禁止剪切板」改为「使用粘贴板」（勾选 = 启用重定向），且**默认勾选**；资产编辑对话框与连接方案抽屉中的同名项同步。

### 3.3 新增：列设置浮层

基线未描述该能力，新增如下：

| 能力 | 说明 |
| --- | --- |
| 列显隐 | 逐列勾选显示/隐藏；「名称」「操作」为必要列，不可隐藏 |
| 列排序 | 每列提供「上移 / 下移」，调整列在表格中的显示顺序 |
| 列表字号 | 下拉选择列表字号，即时生效 |

上述设置随本地配置持久化。

### 3.4 表格视图（§4.4）

- **新增列**：在备注 1/2/3 之后增加「**备注4**」（只读、可排序），列顺序为「…备注1 / 备注2 / 备注3 / 备注4 / 模板 / 协议 / 操作」。
- 其余列定义、行高、斑马纹、临期行高亮、双击建连等约定与基线一致。

### 3.5 宫格视图（§4.5）

与基线一致，未修改。

## 4. 右侧详情面板（基线 §4.1 / §4.7）

### 4.1 展开方式（修改）

- 基线：右侧面板「默认收起，选中资产时按需展开」。
- 现状：**选中资产不再自动展开**。展开/收起唯一入口为顶栏「资产详情」按钮（面板内保留收起按钮）。
- 影响：连接失败时面板同样保持收起状态，不抢占用户视角（详见 §11）。

### 4.2 分辨率快速配置（修改）

- 基线预设：`16:9`、`16:10`、左右/上下对分、恢复默认。
- 现状预设（RDP 资产）：

| 预设 | 取值 |
| --- | --- |
| 1/4 屏 | 屏宽 / 2 × 屏高 / 2 |
| 1/6 屏 | 屏宽 / 3 × 屏高 / 2 |
| 1/9 屏 | 屏宽 / 3 × 屏高 / 3 |
| 左右一分二 | 屏宽 / 2 × 屏高 |
| 上下一分二 | 屏宽 × 屏高 / 2 |
| 恢复默认 | 1920 × 1080 |

- 支持在宽/高输入框中直接手填任意分辨率，随「保存设置」落盘。

### 4.3 新增：SSH 窗口大小

- 基线 §4.7 仅描述 RDP 分辨率；现状为 **SSH 资产也提供同构的「窗口大小」区块**（宽/高输入 + 与 RDP 完全相同的 5 个预设 + 恢复默认，默认 1000 × 640）。
- 显隐规则：选中资产协议为 `ssh` 时显示「窗口大小」、隐藏 RDP「分辨率」；`rdp`/`vnc` 反之。

### 4.4 只读状态卡 / 就地诊断卡 / 全局项 / 保存

- 只读状态卡（到期预警 + 最后检测耗时）、就地诊断卡（原因 + 建议 + 重试）、探测间隔、记住密码、`保存设置` 均保留，与基线一致。

## 5. 连接方案抽屉（基线 §4.3 / §5.2）

- 抽屉结构（概览与继承状态 / 生效值预览 / 保存为模板 / 保存应用）与基线一致。
- **新增**：协议为 `ssh` 时出现「显示设置」区块：

| 控件 | 说明 |
| --- | --- |

- RDP 专属项（分辨率模式、色深、网关、重定向）在非 RDP 协议下隐藏；「当前生效参数预览」保持基线设计。

## 6. 模板体系（基线 §4.8 / §5.2）

- **新增**：模板编辑对话框增加「**SSH 设置**」区，字段为「窗口大小」（宽 × 高，默认 1000 × 640）。
- 显隐规则：协议为 `ssh` 时显示 SSH 设置、隐藏 RDP 设置；`rdp`/`vnc` 反之。
- 校验区间：宽 320–7680、高 240–4320。
- **生效优先级**（连接 SSH 独立窗口时）：**资产自身配置 → 资产绑定的模板 → 产品默认 1000 × 640**。
- 模板管理视图（列表 + 详情 + 新建/编辑/复制/删除 + 按名称/使用次数排序）与基线一致。

## 7. 新增：「设置」页（基线未覆盖）

左侧导航新增「设置」入口，页面分三张卡片：

### 7.1 VNC 客户端配置（自帮助手册迁入）

- 客户端可执行文件路径：文本框 + 「浏览选择」+ 「自动检测」，下方实时状态行（已就绪 / 未检测到 / 路径不存在）。
- 启动参数模板：文本框 + 参数说明 + 「恢复默认参数」。

### 7.2 SSH 终端外观（新增）

| 项 | 说明 |
| --- | --- |
| 字体大小 | 滑块，范围 9–28，右侧实时显示当前值 |
| 配色方案 | 下拉选择（深色 / 绿色 / 浅色），右侧预览色块即时跟随 |

### 7.3 SSH 独立窗口（新增）

- 开关：「SSH 以独立窗口打开」。
- 开启后双击 SSH 资产**直接打开独立窗口**，不加入工作台、不跳转工作台（详见 §9）。
- 关闭时保持基线行为（SSH 内嵌终端进入工作台分屏）。

- 页面底部为 `保存` 主按钮；以上配置随本地设置持久化。

## 9. 新增：SSH 独立窗口

- **触发**：设置页开启「SSH 以独立窗口打开」后，双击 SSH 资产即打开独立窗口（标题为 `资产名 (主机)`），主窗口保持当前视图不变。
- **尺寸**：窗口初始宽高按「资产 → 绑定模板 → 默认 1000 × 640」解析（见 §6）。
- **与工作台的关系**：独立窗口模式下的会话**不占用工作台标签与分屏**；关闭窗口即断开该 SSH 会话。
- 未开启该开关时，SSH 仍为基线行为：内嵌终端进入工作台分屏（§4.6）。

## 10. 资产模型与导入导出（基线 §4.8 / §5.3）

### 10.1 资产编辑对话框

- **新增字段**：「备注4」（与备注 1/2/3 同级）。
- **SSH 专属字段**：密钥路径（可浏览）、密钥口令、跳板机——选择 `ssh` 协议时显示（与基线 §4.8 描述一致，此处仅确认现状）。
- **RDP 重定向**：驱动器 / 音频 / 剪贴板三项；其中「剪贴板」文案为「使用粘贴板」且**默认勾选**（见 §3.2）。

### 10.2 导出字段对话框

- **新增字段**：备注4、协议、端口、密钥路径。
- **敏感项**（红色标注）：密码、密钥路径，默认不勾选（密钥路径默认不勾选；见对话框现状）。

### 10.3 CSV 导出 / 导入

- 导出新增列：`其他备注4`、`协议`。
- 导入兼容别名：备注4（`其他备注4` / `备注4` / `备4` / `Note4` / `CustomNote4`）、协议（`协议` / `Protocol`）。
- 其余列与基线 §5.3 一致。

### 10.4 数据模型（存储层）

- 新增字段均为**可选/带默认值**，旧数据文件无需迁移即可读取，写入为向前兼容的"新增字段"策略。
- SSH 独立窗口尺寸按资产（可为空）与按模板（默认 1000×640）双份存储。

## 11. 运行期行为（基线未覆盖）

### 11.1 单实例运行

- 重复启动应用时，**第二个实例立即退出**，并激活已有主窗口（置前显示），不产生第二个窗口与第二份内存状态。
- 退出首个实例后，锁释放，可正常再次启动。

### 11.2 连接失败反馈（修改基线 §5.5）

- 基线：`失败 → 状态栏提示 + 详情面板出现诊断卡`。
- 现状：失败原因**统一显示在底部状态栏**，详情面板**保持收起、不自动弹出**。用户可手动经「资产详情」按钮打开面板查看诊断卡与重试入口。
